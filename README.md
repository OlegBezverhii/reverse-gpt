# Reverse-GPT 🤖🔍

**Reverse-GPT** — это автономный ИИ-агент для реверс-инжиниринга бинарных файлов. В отличие от простых скриптов, он использует агентную архитектуру на базе **LangGraph**, что позволяет ему самостоятельно принимать решения о ходе исследования, переходить между функциями и анализировать память бинарника.

Инструмент объединяет мощь декомпилятора **Ghidra** и рассудительность современных языковых моделей (LLM) через **Groq API**.

## ✨ Основные возможности

*   **Автономное исследование:** Агент сам определяет точку входа, анализирует структуру и решает, какие функции требуют детального изучения.
*   **Интеграция с Ghidra:** Прямой доступ к декомпилятору, списку функций и байтам памяти через библиотеку `pyhidra`.
*   **Интерактивный чат:** Возможность задавать вопросы о логике работы программы на естественном языке.
*   **Умная декомпиляция:** Модуль нормализации кода преобразует непонятные переменные (типа `uVar1`) в осмысленные имена и добавляет поясняющие комментарии.
*   **Защита от зацикливания:** Встроенные механизмы контроля лимитов вызова инструментов.

## 🏗 Архитектура

Проект построен на базе **StateGraph** (граф состояний):
1.  **Analyze:** Сбор метаданных (архитектура, секции, Entry Point).
2.  **Report:** Генерация первичного резюме о файле.
3.  **Chatbot/Tools Loop:** Циклический процесс, где LLM запрашивает данные у Ghidra, получает результат и уточняет свой ответ до тех пор, пока не удовлетворит запрос пользователя.

## 🚀 Быстрый старт

### Требования
*   Python 3.11+
*   **Ghidra** (установленная в системе)
*   **JDK 17+** (необходим для работы Ghidra/Pyhidra)
*   Ключ API от [Groq Cloud](https://console.groq.com/)

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/reverse-gpt.git
cd reverse-gpt
```

2. Установите зависимости (рекомендуется использовать `uv` или `venv`):
```bash
pip install -r requirements.txt
# Или через uv:
uv sync
```

3. Настройте переменные окружения:
Создайте файл `.env` в корне проекта:
```env
GROQ_API_KEY=your_api_key_here
GHIDRA_INSTALL_DIR=/path/to/your/ghidra_folder
```

### Использование

Запустите основной интерфейс:
```bash
python main.py
```

1. Введите путь к бинарному файлу.
2. Дождитесь завершения первичного анализа.
3. Задавайте вопросы (например: *"Найди функцию проверки пароля и объясни алгоритм ее работы"*).

## 🛠 Доступные инструменты агента

Агент может вызывать следующие функции Ghidra:
*   `analyze_binary_structure()` — общая информация о бинарнике.
*   `list_functions()` — получение списка всех символов и адресов.
*   `get_decompiled_code_at_address(addr)` — получение C-подобного псевдокода.
*   `read_memory_bytes(addr, size)` — чтение данных напрямую из секций.
*   `run_python_code(code)` — выполнение произвольных расчетов для анализа.

### 💡 Почему LangGraph?
Использование графов позволяет нам строить сложные циклы «рассуждение — действие — наблюдение». Если ИИ видит, что декомпиляция функции не дала ответа, он может «сделать шаг назад», прочитать таблицу строк или заглянуть в вызывающую функцию, имитируя поведение реального реверс-инженера.
