# Reverse-GPT 🤖🔍

Это форк проекта [kalikhalid/reverse-gpt](https://github.com/kalikhalid/reverse-gpt), только доработанный под мои нужды, а именно использование API DeepSeek.

## ✨ Нововедения

- **Кэш проекта Ghidra:** повторный запуск открывает уже проанализированный проект, а не пересобирает его заново.
- **Защита от зацикливания:** дедупликация одинаковых вызовов, детектор отсутствия прогресса и жёсткие лимиты.
- **Устойчивость к ошибкам модели:** авто-исправление невалидного JSON в аргументах инструментов и «починка» истории сообщений.
- **Аккуратное завершение:** при выходе проект Ghidra закрывается, JVM останавливается, процесс не подвисает.


## 🛡 Надёжность и защита от зацикливания

- **Дедупликация вызовов:** повторный вызов с теми же `name+args` не выполняется — модели возвращается предыдущий результат.
- **Детектор застоя:** после `MAX_STAGNANT_STEPS` (3) шагов без новых вызовов агент обязан дать финальный ответ.
- **Лимит вызовов:** `MAX_TOOL_CALLS` (30) на один вопрос.
- **Обработка `tool_calls`:** ответ формируется на **каждый** `tool_call_id`, включая невалидные, иначе DeepSeek возвращает ошибку 400.
- **Починка JSON:** аргументы вида `{"size": 0x100}` автоматически приводятся к валидному JSON (`256`).
- **Починка истории:** перед вызовом модели история нормализуется, чтобы у каждого `tool_calls` был корректный tool-ответ.
- **Кэш Ghidra:** существующий проект переиспользуется; при желании можно форсировать повторный анализ.


## 🚀 Быстрый старт

### Требования
*   Python 3.11+
*   **Ghidra** (установленная в системе)
*   **JDK 17+** (необходим для работы Ghidra/Pyhidra)
*   Учетные данные от [DeepSeek API](https://platform.deepseek.com/)

### Установка

```bash
git clone https://github.com/<your-username>/reverse-gpt.git
cd reverse-gpt

# Рекомендуется uv (есть uv.lock)
uv sync

# Либо через venv + pip
python -m venv .venv
.venv\Scripts\activate      # Windows
# source .venv/bin/activate # Linux/macOS
pip install -e .
```

> Важно: запускайте приложение интерпретатором из `.venv` (или через `uv run`), иначе получите `ModuleNotFoundError: No module named 'langchain_deepseek'`.

## ⚙️ Настройка

Создайте файл `.env` в корне проекта (он в `.gitignore` и **не** должен попадать в git):

```env
DEEPSEEK_API_KEY=your_api_key_here
GHIDRA_INSTALL_DIR=C:\path\to\ghidra
# Необязательно: модель DeepSeek (по умолчанию deepseek-chat)
# DEEPSEEK_MODEL=deepseek-chat
```

- `GHIDRA_INSTALL_DIR` — путь к установленной Ghidra.
- Для tool-calling надёжно подходит `deepseek-chat`. У `deepseek-reasoner` возможны проблемы с вызовом инструментов.

Пример готового шаблона в репозиторий представлен в файле `.env.example` (без секретов).

## ▶️ Запуск

```bash
uv run main.py
# или
.venv\Scripts\python.exe main.py
# или (Linux/macOS)
./run.sh
```

Можно и по старинке, но смотрите, чтобы все пакеты были установлены:
```bash
python main.py
```

1. Введите путь к бинарному файлу.
2. Если для файла уже есть сохранённый проект Ghidra — приложение спросит, открыть без повторного анализа или переанализировать.
3. Дождитесь первичного отчёта.
4. Задавайте вопросы, например: *«Найди функцию проверки пароля и объясни алгоритм её работы»*.
5. Выход — `exit` или `quit`.
